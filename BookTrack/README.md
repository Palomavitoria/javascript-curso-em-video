
# 📚 BookTrack

**Gerenciador de Biblioteca Pessoal**

O BookTrack é uma aplicação web desenvolvida como projeto final do curso de JavaScript. Seu objetivo é permitir o gerenciamento de uma biblioteca pessoal de maneira simples e organizada.

Com ele, é possível cadastrar livros, acompanhar o progresso das leituras, editar informações, pesquisar títulos e visualizar estatísticas da biblioteca.

## ✨ Funcionalidades

- **Cadastro de livros:** adicione livros informando título, autor, gênero e quantidade de páginas.
- **Edição:** atualize as informações dos livros cadastrados.
- **Exclusão:** remova livros da biblioteca.
- **Pesquisa:** encontre livros pelo título, autor ou gênero.
- **Controle de leitura:** organize os livros por status:
  - Quero ler;
  - Lendo;
  - Lido.
- **Estatísticas:** acompanhe o total de livros, livros lidos, livros em andamento, livros que deseja ler e quantidade total de páginas.
- **Armazenamento local:** os dados ficam salvos no navegador por meio do LocalStorage, mesmo após fechar a página.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em seu navegador.
4. Comece a cadastrar e organizar seus livros!
